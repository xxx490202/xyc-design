## Monitor snapshot

`monitor.html` reads a static snapshot from `monitor-data.js` — no backend, so it
works on GitHub Pages. To refresh it on this machine:

```bash
python3 tools/build_monitor_data.py
```

The script pulls 18 public hot lists through the same newsnow endpoint TrendRadar
uses, reuses the province / country / category tables from
`~/Desktop/Quantification/sentiment.py` (override with `SENTIMENT_PY=...`), and
rewrites `monitor-data.js`. The two map SVGs live in `img/map/` and are inlined at
runtime for hover, tinting and region clicks.

### Hourly refresh (GitHub Actions)

`.github/workflows/monitor.yml` runs `tools/build_monitor_data.py` every hour at
:17 and commits `monitor-data.js` only when the snapshot changed. It needs no
secrets — only **Settings → Actions → General → Workflow permissions → Read and
write permissions**. Trigger it once by hand from the Actions tab
(`workflow_dispatch`) to seed the first run.

The script is self-contained (Python standard library only); it does not need the
Quanta app or any local path. GitHub Pages may cache `monitor-data.js` for about
ten minutes, so a fresh commit can take a few minutes to appear.

## Live data (optional)

The newsnow endpoint sends no CORS header, so the browser cannot call it
directly. `worker/` contains a tiny proxy with the same JSON shape as
`monitor-data.js`:

- `worker/worker.js` — Cloudflare Worker (`cd worker && npx wrangler deploy`)
- `worker/server.mjs` — Node 18+ fallback (`node worker/server.mjs`)
- `worker/rules.js` — generated from `tools/build_monitor_data.py`; regenerate
  with `python3 tools/gen_worker_rules.py`

After deploying, open **Monitor → Sentiment settings → Live proxy**, paste the
URL (`https://…workers.dev/api/monitor` or `http://localhost:8787/api/monitor`)
and press **Use**. It is stored in `localStorage`; **Start monitoring** then
fetches live data, and clearing the field returns to the bundled snapshot. To
ship a default instead, put the URL in `monitor-live.js`.

## Build / asset notes

- Hot lists are baked hourly by `.github/workflows/monitor.yml` into
  `monitor-data.js` (static, GitHub Pages friendly).
- `img/line/*.webp` are resized, lossless WebP copies of the line art (340 KB
  total instead of 2.1 MB of PNG).
- `img/map/*.svg` were stripped of hidden label groups and simplified with a
  1 px Douglas–Peucker pass; the world sheet went from 1.79 MB to 360 KB
  (135 KB gzipped).
- Images below the fold use `loading="lazy"`; the hero plate is preloaded and
  keeps `fetchpriority="high"`.

## ComfyUI workflows

`comfyui.html` shows four SDXL Turbo graphs from `~/Desktop/ComfyUI/workflow`.
The raw graphs live in `comfy/workflows/`; `comfy-data.js` is generated by
`python3 tools/build_comfy_data.py`, which also extracts the node positions,
links, prompts and sampler settings the page draws.
