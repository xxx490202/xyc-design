How it is made

Collected, located, ranked.

The same three steps as the desktop app, running as a build script instead of a backend.

  1. 01
    Collect

    Eighteen public hot lists, read through the same newsnow endpoint TrendRadar uses. Duplicate stories are merged and every board that carried one is kept.

  2. 02
    Locate

    Place names in each headline are matched to China's 34 province-level regions and 80 countries. Headlines without a place stay in the feed but not on the map.

  3. 03
    Rank

    Heat is board position multiplied by the number of boards carrying the story. A region is tinted at 1–5, 6–10 and 11+ stories; the badge is the count.

  4. 04
    Freeze

    The last round is written to monitor-data.js at build time. GitHub Pages serves that file — which is why this page needs no backend.
